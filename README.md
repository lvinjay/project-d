# Project D v3.0

제품 스펙과 리뷰 요약 데이터를 기반으로, 사용자의 예산과 중요도에 맞는 제품을 추천하는 Next.js MVP입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.

## 현재 구현 기능

- 메인 랜딩 페이지
- 제품 검색 및 정렬
- 후보 제품 2~5개 선택
- URL 기반 선택 상태 유지
- 예산 및 5개 중요도 입력
- 가중치 기반 추천 순위 계산
- 추천 이유와 구매 전 주의점
- 리뷰 분석 근거 표시
- 모바일 반응형 화면

## 중요 안내

현재 제품 스펙과 리뷰 분석 근거는 데모 데이터입니다. 실제 상용 서비스에서는 공식 제품 정보, 적법하게 확보한 리뷰 데이터, 출처 및 업데이트 시점을 DB에 저장해야 합니다.
