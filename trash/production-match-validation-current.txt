        - S10 MaxV Ultra -> 로보락 세제 : 차단
        - S10 MaxV Ultra -> S10 MaxV Slim : 차단
        - X60 Ultra -> X60 Ultra : 허용

        숫자/영문이 섞인 모델 토큰을 우선 비교한다.
      */
      const getModelTokensForValidation = (
        value: string,
      ) =>
        String(value ?? "")
          .toLowerCase()
          .replace(/[^a-z0-9]+/g, " ")
          .split(/\s+/)
          .map((token) => token.trim())
          .filter(
            (token) =>
              token.length >= 2 &&
              /[a-z]/.test(token) &&
              /\d/.test(token),
          );

        getModelTokensForValidation(

            .filter(Boolean)

        );

        S10 MaxV Ultra -> S10 MaxV Slim : 차단
        X60 Ultra -> X60 Ultra : 허용

      */

        "slim",

        "max",
