Project D v3.1 설치/교체 방법

1. 실행 중인 개발 서버에서 Ctrl+C를 눌러 종료합니다.
2. 현재 Project D 폴더의 frontend 폴더 이름을 frontend_backup_v30으로 변경합니다.
3. 이 압축파일 안의 frontend 폴더를 Project D 폴더에 복사합니다.
4. VS Code에서 새 frontend 폴더를 엽니다.
5. 터미널에서 npm install 을 실행합니다.
6. 설치 후 npm run dev 를 실행합니다.
7. 브라우저에서 http://localhost:3000 을 확인합니다.

정상 확인 경로
- 메인: /
- 제품 선택: /search
- 조건 설정: /question?ids=1,2
- 결과 예시: /result?ids=1,2&budget=500000&cooling=5&quietness=4&portability=4&battery=3&afterService=3
